**thundering herd** _n._ [J](http://www.catb.org/jargon/html/T/thundering-herd-problem.html) A failure mode in which a large number of processes or clients simultaneously attempt to access a resource, overwhelming it. The name comes from the image of a herd of animals stampeding together. In distributed systems it typically occurs when a shared cache expires or a server recovers from downtime: every client that was waiting fires its request at exactly the same moment, often crashing the system they were waiting to use. It can also be caused by synchronized retry logic — if all clients wait the same fixed interval and then retry together, the problem repeats on a loop.
Solutions include jitter (randomizing retry intervals), cache stampede prevention, and rate limiting. The thundering herd is an example of emergent behavior: each individual client is doing the sensible thing, but the collective behavior is catastrophic. #AI-Gen
